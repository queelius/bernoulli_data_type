\title{The Bernoulli Model: A Probabilistic Framework for Data Structures and Types}
\author{Alexander Towell\\\texttt{atowell@siue.edu}}
\date{}

\begin{document}

\maketitle

\begin{abstract}
Building on the Bernoulli set model~\cite{bernoulliSets}, this note recasts it as a probabilistic model indexed by data types, particularly Boolean values: a value of type $T$ is observed through a channel (confusion matrix) conditioned on a latent value. We discuss model order, Bayesian prediction of the latent value, lifting exact functions to noisy arguments, set-indicator functions such as Bloom filters, and the error of logic gates applied to noisy Booleans, where the error rate of the output depends on the latent input assignment. Cipher data types are mentioned as a motivation only. The individual results are known (randomized response, binary channels, signal-probability analysis of circuits, and probability types for approximate programs); the note is a type-indexed presentation of them.
\end{abstract}
